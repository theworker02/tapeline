# tapeline

Tape identifiers and line tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tapeline/

## Install / run

```bash
git clone https://github.com/theworker02/tapeline.git
cd tapeline
node src/cli.js
node --test
```
